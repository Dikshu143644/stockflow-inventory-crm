# Multi-branch, barcode scanning, mobile polish, and QA infrastructure (v2)

Phase 8 delivers branch management (context, CRUD page, selector), a camera-based barcode scanner with product lookup, PWA/mobile enhancements, and a Vitest test harness. The six issues raised in v1 have all been addressed: BranchSelector now uses the `useBranches` hook, BranchesPage is wired to real mutations, search input is sanitized, the service worker has version-based cache eviction and an LRU trim, barcode lookup retries on transient errors, and `useProducts`/`useWarehouses` accept `branch_id` as a filter parameter.

**Verdict**: NEEDS_CHANGES

## Issues (3)

1. **Branch selector has no downstream data effect** - No page component passes `currentBranchId` from BranchContext to `useProducts` or `useWarehouses`. Add a consuming pattern in the Products page so the branch filter actually works end-to-end.
2. **BranchesPage CRUD has no error feedback** - `onSubmit` and `confirmDelete` lack `onError` callbacks. Add a toast notification on mutation failure using Sonner (already in the app).
3. **Search sanitization strips rather than escaping** - `useBranches` replaces `.`, `,` etc with empty strings. Low severity but "St. Louis" becomes "St Louis".
